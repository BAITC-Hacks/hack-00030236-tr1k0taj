# 0014. OpenAI-адаптеры для голосового демо

- Статус: accepted
- Дата: 2026-09-23
- Автор: Aidar

## Контекст
По поручению владельца нужно запустить локальное демо с микрофоном. Доступ к OpenAI подтверждён реальным ответом kernel, но штатный call API пока регистрирует только моки речи и роутера.

## Решение
Добавляем адаптеры OpenAI STT/TTS и LLM-роутера за существующими портами speech/router. Это уточняет выбор провайдера ADR 0008. HTTP/SSE, политика маршрутизации и исполнитель не меняются. Ключ используется только сервером из env; безопасные дефолты репозитория остаются mock. Модель роутит по полному каталогу Knowledge и возвращает текущий RouterOutput.

## Альтернативы
- Прямой OpenAI из браузера — раскрывает ключ и дублирует backend.
- Ждать адаптеры — не даёт проверить микрофон сейчас.

## Последствия
Можно проверить push-to-talk от записи до ответа через /calls. Поддержка и качество казахского требуют проверки реальной речью; наличие адаптеров не означает поддержку всех действий исполнителя. Работа без ключей сохраняется.
