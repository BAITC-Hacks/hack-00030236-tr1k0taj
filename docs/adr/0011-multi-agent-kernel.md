# 0011. Streaming blackboard kernel и общий RAG

- Статус: accepted
- Дата: 2026-09-23
- Основание: явное поручение владельца реализовать новый план.
- Спека: [agent-kernel.md](../specs/agent-kernel.md).

## Контекст
Нужны N фоновых агентов и один главный, который использует их результаты
внутри текущего streaming-ответа. Frontend сообщает позицию прерывания аудио.

## Решение
- Postgres append-only журнал, session snapshot, один backend process и asyncio orchestrator.
- Главный генерирует короткие сегменты с новым снимком контекста; токены сегмента стримятся.
- Фон работает через read-only RAG Knowledge, результаты и tool calls остаются внутренними.
- Публичный SSE содержит только пользовательский диалог и lifecycle; trace — отдельная проекция.
- seq, input_revision и generation разделены; независимые результаты одной ревизии совместимы.
- Interrupt закрывает response_id, отменяет главный stream; актуальный фон может продолжаться.
- История хранит played_ms и timeline, отличает heard/partial/unheard/unknown.
- RAG расширяет PR #2: OpenAI embeddings + pgvector и честный lexical fallback.
- Эта спека заменяет соответствующие ограничения ADR 0003/0006/0008 и старый лимит
  двух LLM-вызовов. Вместо него явные лимиты сегментов, tools, времени и параллельности.

## Последствия
Дополнительные LLM-вызовы дают паузы между сегментами; измеряем их, мгновенную
инъекцию в уже запущенную генерацию не обещаем. Один worker — явное ограничение v1.
Аудиотракт и UI используют опубликованный контракт, реализуются отдельно от ядра.
