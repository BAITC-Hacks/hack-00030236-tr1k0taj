# 0014. Blackboard: задачи, зависимости записей и единая история

- Статус: accepted
- Дата: 2026-09-23
- Спека: [blackboard-v2](../specs/blackboard-v2.md).

## Контекст
Новые реплики сейчас отменяют весь фон, а router и kernel используют разные истории.
Нужны исправления, переключение задач и delivery-aware контекст для чата/голоса.

## Решение
Contexts остаётся единственным писателем. В существующей JSONB projection храним
задачи и версионированные записи blackboard; изменения фиксируются в журнале.
Актуальность результатов определяется generation, task и версиями прочитанных ключей.
По умолчанию агент зависит от текущего сообщения; явные reads сужают его контекст.
Общий projector собирает историю для всех читателей и сохраняет delivery каждого сегмента.
Call ingress получает idempotency и persisted public replay, без повторного запуска модели.
Поздние фоновые результаты не запускают внешнюю речь автоматически.

## Альтернативы
- Отдельный LLM-координатор памяти — дополнительные задержки и неопределённость.
- Отмена всего фона на каждую реплику — теряет полезные независимые результаты.

## Последствия
Сохраняем один процесс и текущую БД, без новой инфраструктуры. Исправления входных данных
поступают явными контрактами от router/integrator. Авторизация организаций и возобновление
задач после падения остаются отдельными задачами, не выдаются за готовые свойства v2.
