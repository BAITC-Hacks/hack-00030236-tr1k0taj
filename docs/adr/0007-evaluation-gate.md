# 0007. Оценка качества роутера и гейт

- Статус: accepted
- Дата: 2026-09-23
- Автор: ye
- Спека: docs/specs/voice-router-spec.md (разд. 11)

## Контекст
Точность на 10 скрытых репликах жюри — 25 баллов. Нужна автоматическая метрика до демо.

## Решение
- `just eval`: реальная модель генерирует predictions по всем 104 репликам `dev_utterances.json`, затем вызывается исходный `evaluate.py` из кита.
- Ожидаемые ответы видит только evaluator. Роутер и промпт их не читают.
- Сохраняем primary accuracy, full match, multi-intent recall с разбивкой ru / kk / mixed. Результаты — в README.
- Eval всегда на чистом исходном наборе.
- Гейт на минуте 90 (см. ADR 0006).
- `just test` не вызывает LLM: только ключевые тесты кода (валидация ответа роутера, пороги, подтверждения, применение патча).

## Последствия
- Каждое изменение карточек и промпта проверяется одной командой.
